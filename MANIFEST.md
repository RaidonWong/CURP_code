# Release manifest

This repository contains the maintained CURP training and inference path plus
the paper's main ablations.

Intentionally excluded:

- LaMP and LongLaMP source or processed data;
- profile embedding tensors;
- Stage-1 and Stage-2 checkpoints;
- generated predictions and evaluation logs;
- rebuttal drafts, internal plans, and user-study records;
- copied third-party repositories and package source trees;
- machine-local editor and assistant configuration.

The release should remain source-only. Add external artifacts through documented
download instructions instead of committing them to Git.
